Le parcours utilisateur semble fragmenté

The user journey appears fragmented

Trois entrées parallèles, une navigation qui semble bloquée dans le chat IA, et un projet qui paraît ne pas être sauvegardé automatiquement. Ces observations sont basées sur une exploration externe et nécessitent une validation avec les équipes internes.

Three parallel entry points, navigation that appears blocked inside the AI chat, and a project that seems not to be automatically saved. These observations are based on external exploration and need validation with internal teams.

Observations terrain
Field observations

Ce qui a été observé

What was observed

MoyenMedium

Trois entrées, aucune hiérarchie claire

Three entry points, no clear hierarchy

La homepage propose trois chemins distincts vers le même objectif: la barre de recherche, le bouton "On vous aide à choisir" (chat IA) et la navigation Destinations/Explorer. Il ne semble pas y avoir d'indicateur guidant l'utilisateur vers le bon point d'entrée selon son niveau de maturité dans le projet. Le Trip Designer beta paraît dissocié de ce flux principal. Cela dit, il serait utile de valider avec les équipes si cette multiplicité est intentionnelle.

The homepage presents three distinct paths to the same goal: the search bar, the 'On vous aide à choisir' AI chat, and the Destinations/Explorer navigation. There does not seem to be any indicator guiding the user to the right entry point based on their trip planning maturity. The Trip Designer beta appears disconnected from this main flow. That said, it would be worth validating with the teams whether this multiplicity is intentional.

⚠ À valider: Taux d'abandon en début de parcours. Répartition des utilisateurs entre les 3 entrées. À mesurer via funnel analytics avant toute décision.
⚠ To validate: Drop-off rate at journey start. User distribution across the 3 entry points. To measure via funnel analytics before any decision.
MoyenMedium

Navigation bloquée dans le chat IA

Navigation blocked in the AI chat

Lors de l'exploration du flux "On vous aide à choisir", il n'a pas été possible de revenir à la homepage ou au compte utilisateur via la navigation standard. Le bouton retour du navigateur et les liens habituels ne semblaient pas fonctionner. Par contraste, le flux "planifier votre voyage" accessible depuis une page de destination permettait un retour normal. Il se peut que cette expérience soit liée à un bug ou à une configuration spécifique, et mériterait d'être reproduite pour confirmer.

During exploration of the 'On vous aide à choisir' flow, it was not possible to return to the homepage or user account via standard navigation. The browser back button and regular links did not seem to work. By contrast, the 'planifier votre voyage' flow accessible from a destination page allowed normal navigation back. This may be related to a specific bug or configuration and would be worth reproducing to confirm.

⚠ À valider: Taux de rebond depuis le chat. Sessions abandonnées sans action suivante. À reproduire et confirmer en interne.
⚠ To validate: Bounce rate from chat. Sessions abandoned with no next action. To reproduce and confirm internally.
MoyenMedium

L'itinéraire ne semble pas sauvegardé automatiquement

The itinerary does not appear to be automatically saved

Dans le flux "On vous aide à choisir", l'itinéraire généré ne semble pas apparaître dans "Mes voyages" si l'utilisateur décide de ne pas envoyer son projet à une agence. Cela signifie qu'un utilisateur qui souhaite réfléchir avant de contacter une agence repart potentiellement de zéro lors de sa prochaine visite. Cette observation mériterait d'être validée avec l'équipe produit, car il est possible qu'une logique de sauvegarde existe mais ne soit pas visible côté utilisateur.

In the 'On vous aide à choisir' flow, the generated itinerary does not appear in 'Mes voyages' if the user decides not to send their project to an agency. This means a user who wants to think before contacting an agency may potentially start from scratch on their next visit. This observation should be validated with the product team, as it is possible that a save logic exists but is not visible on the user side.

⚠ À valider: Taux de retour sur la plateforme dans les 30 jours. Part des utilisateurs qui complètent sans envoyer à une agence. À valider avec les données internes.
⚠ To validate: 30-day return rate. Share of users who complete without sending to an agency. To validate with internal data.

Si nous agissons sur ces frictions

If we act on these friction points

Ces hypothèses sont des points de départ, pas des vérités. Les chiffres proposés sont indicatifs et devront être calibrés avec les données réelles.

These hypotheses are starting points, not truths. The proposed figures are indicative and will need to be calibrated with real data.

H1
Sauvegarde automatique · Rétention
Auto-save · Retention

Si nous sauvegardons automatiquement l'itinéraire du Trip Designer dans le compte utilisateur (que l'utilisateur contacte ou non une agence), nous estimons que le taux de retour sur la plateforme dans les 30 jours pourrait augmenter, et que le taux de conversion final vers une réservation agence pourrait également progresser.

If we automatically save the Trip Designer itinerary to the user's account regardless of whether they contact an agency, we estimate the 30-day return rate could increase, and the final agency booking conversion rate could also improve.

Taux de retour 30 jours. Taux de conversion agence. DAU/MAU.
30-day return rate. Agency conversion rate. DAU/MAU.
Validation
Validation

Before/after cohort analysis. Minimum 4 weeks.
H2
Navigation chat · Expérience
Chat navigation · Experience

Si nous rétablissons une navigation standard dans le flux chat IA (retour homepage, retour compte), nous anticipons une réduction du taux d'abandon dans ce flux, et une meilleure perception de la fluidité de l'expérience.

If we restore standard navigation inside the AI chat flow (back to homepage, back to account), we anticipate a reduction in drop-off rate in this flow and improved perception of experience fluidity.
