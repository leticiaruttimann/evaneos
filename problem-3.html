Différenciation et mémoireDifferentiation and memory

La valeur différenciante d'Evaneos vs un LLM généraliste n'est pas claire au bon moment

Evaneos's differentiating value vs a generic LLM is not clearly surfaced at the right moment

Pourquoi utiliser le Trip Designer plutôt que ChatGPT? La connexion avec des agences vérifiées est la vraie réponse. Mais elle ne semble pas être mise en avant assez tôt. De plus, l'absence de mémoire entre les sessions prive Evaneos d'un avantage concurrentiel majeur.

Why use Trip Designer over ChatGPT? The connection with vetted agencies is the real answer. But it does not seem to be surfaced early enough in the journey. Additionally, the lack of memory between sessions deprives Evaneos of a major competitive advantage.

La proposition de valeur unique d'Evaneos n'est pas mise en avant au début du parcours

Evaneos's unique value proposition is not surfaced at the start of the journey

Lors de l'exploration du Trip Designer, il n'a pas semblé évident pourquoi utiliser cet outil plutôt qu'un LLM généraliste comme ChatGPT. La connexion avec des agences locales vérifiées est la vraie différence, mais elle ne semble pas être communiquée dès les premières interactions. Un utilisateur non familier avec Evaneos pourrait difficilement percevoir cette valeur ajoutée.

During Trip Designer exploration, it was not immediately obvious why to use this tool over a generic LLM like ChatGPT. The connection with vetted local agencies is the real difference, but it does not seem to be communicated from the first interactions. A user unfamiliar with Evaneos may struggle to perceive this added value.

A valider: Taux de finalisation du parcours Trip Designer. Entretiens qualitatifs sur la perception de la valeur.
To validate: Trip Designer flow completion rate. Qualitative interviews on value perception.

Pas de mémoire entre les sessions utilisateur

No memory between user sessions

Le Trip Designer ne semble pas retenir les préférences de l'utilisateur entre les sessions. Si Marie Curie planifie un voyage en France en été, refuse de prendre l'avion et a des restrictions alimentaires, ces informations ne semblent pas être réutilisées lors de sa prochaine visite pour planifier l'Italie. C'est une opportunité majeure de personnalisation.

Trip Designer does not appear to retain user preferences between sessions. If Marie Curie plans a summer trip to France, refuses to fly and has dietary restrictions, this information does not seem to be reused on her next visit to plan Italy. This is a major personalisation opportunity.

A valider: Taux de retour avec Trip Designer. Temps de re-saisie des préférences. NPS comparatif utilisateurs récurrents vs nouveaux.
To validate: Return rate with Trip Designer. Preference re-entry time. Comparative NPS recurring vs new users.

Agentic AI opportunity

La mémoire comme différenciateur durable

Memory as a lasting differentiator

🧠

Mémoire agentique persistante

Persistent agentic memory

Un système qui retient les préférences à travers les sessions: phobie de l'avion, restrictions alimentaires, occasions spéciales, budget habituel. A chaque retour, le Trip Designer propose un itinéraire personnalisé sans que l'utilisateur ait à tout réexpliquer.

A system that retains user preferences across sessions: flight phobia, dietary restrictions, special occasions, usual budget. On each return, Trip Designer proactively proposes a personalised itinerary without the user needing to re-explain everything.

📋

Brief automatique pour l'agence

Automatic brief for the agency

Un agent qui génère automatiquement un brief structuré pour l'agence locale en fin de Trip Designer, incluant toutes les préférences capturées au fil de la conversation. L'agence reçoit un contexte riche dès le premier contact.

An agent that automatically generates a structured brief for the local agency at the end of Trip Designer, including all preferences captured throughout the conversation. The agency receives rich context from the very first contact.

Scénario concret: Marie Curie planifie la France en été via Trip Designer. Elle ajuste l'itinéraire, pose des questions sur la nourriture. Quelques mois plus tard, elle revient pour l'Italie. Le Trip Designer se souvient: pas d'avion, restrictions alimentaires, anniversaire en juillet. Il propose proactivement un itinéraire sur mesure. C'est là que la différence avec ChatGPT devient évidente et concrète.

Concrete scenario: Marie Curie plans France in summer via Trip Designer. She adjusts the itinerary, asks about food. A few months later she returns for Italy. Trip Designer remembers: no flights, dietary restrictions, July birthday. It proactively proposes a tailored itinerary. This is where the difference from ChatGPT becomes obvious and concrete.

H5
Valeur différenciante · Adoption
Differentiating value · Adoption

Si nous mettons en avant de façon explicite la valeur unique d'Evaneos (agences vérifiées, expertise locale, impact responsable) dès la première interaction du Trip Designer, le taux de finalisation du parcours pourrait augmenter car l'utilisateur comprend pourquoi utiliser Evaneos plutôt qu'un LLM généraliste.

If we explicitly surface Evaneos's unique value (vetted agencies, local expertise, responsible impact) from the first Trip Designer interaction, flow completion rate could increase as users understand why to use Evaneos over a generic LLM.

H6
Mémoire agentique · Rétention et conversion
Agentic memory · Retention and conversion

Si nous implémentons un système de mémoire persistante retenant les préférences utilisateur entre les sessions, le taux de retour sur la plateforme et le taux de conversion vers une réservation agence pourraient augmenter de façon significative, particulièrement pour les utilisateurs récurrents.

If we implement a persistent memory system retaining user preferences between sessions, the platform return rate and agency booking conversion rate could increase significantly, particularly for returning users.
