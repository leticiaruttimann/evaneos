Grubster

Capstone du certificat en Product Management de York University. Né d'une frustration personnelle en voyage: ne pas pouvoir savoir combien coûte vraiment un repas avant d'entrer dans un restaurant.

Capstone from York University's Product Management certificate. Born from a personal travel frustration: not knowing how much a meal would actually cost before walking in.

J'ai utilisé Claude Code pour construire et déployer l'application, en lui fournissant toute la documentation produit que j'avais créée pendant le cours: personas, user stories, roadmap, prototype Figma.

I used Claude Code to build and deploy the application, providing it with all the product documentation I had created during the course: personas, user stories, roadmap, Figma prototype.

Projet 02 · En cours
Project 02 · In progress

Pipeline agentique PM

Agentic PM pipeline

Je lis une page Notion, et l'agent gère tout le reste: user stories dans Jira, emails de notification, décision de développement, code via Claude Code, mise à jour Jira.

I read a Notion page, and the agent handles everything else: user stories in Jira, notification emails, development decision, code via Claude Code, Jira update.

L'objectif est d'automatiser toutes les activités manuelles qui n'apportent pas de valeur dans le quotidien d'un Product Manager. Une interface UI/UX est en cours de développement et sera publiée prochainement.

The goal is to automate all manual activities that add no value to a Product Manager's daily work. A UI/UX interface is currently in development and will be published soon.
